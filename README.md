# Gaganprajapati Trulang

## How do I install these formulae?

`brew install gaganprajapati/trulang/<formula>`

Or `brew tap gaganprajapati/trulang` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gaganprajapati/trulang"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
